# Ticket 2 – Slow Computer

## Issue
User reports that computer is running very slowly.

## Environment
- Windows 11 VM

## Tools Used
- Task Manager
- Startup Manager

## Troubleshooting Steps
1. Opened Task Manager and checked CPU/RAM usage
2. Ended unnecessary background processes
3. Disabled unnecessary startup programs
4. Verified improvement in system performance

## Root Cause
Too many background processes and startup programs consuming resources.

## Resolution
Ended unnecessary processes and disabled non-essential startup apps.

## Verification
Observed faster response and reduced CPU/RAM usage.
